# Atribuição — viral-mechanism.md

`viral-mechanism.md` é uma adaptação em português do método de
https://github.com/sharon-laicc/viral-video-decomposer (commit 3409359): campos do padrão
viral, tabela de planos, briefing JSON e guarda-corpos de originalidade. Acrescentamos a
seção de sinais de desempenho (engajamento por seguidor, índice de destaque, comentários
por 1.000 curtidas).
